# Installed skills

Design/animation/web-dev skills curated from three sources, for building
Awwwards-quality sites (scroll storytelling, motion, 3D/WebGL, refined UI):

- **Emil Kowalski** — https://github.com/emilkowalski/skills
  (`animate`, `improve-animations`, `review-animations`, `emil-design-eng`, …)
- **Meng To** — https://github.com/MengTo/skills
  (`agent-skills/ui`, `agent-skills/web-design`, `agent-skills/3d`, `agent-skills/media`
  categories only; `codex` and `game-development` were skipped as out of scope)
- **freshtechbro/claudedesignskills** — https://github.com/freshtechbro/claudedesignskills
  (extracted `.claude/skills/*` entries: GSAP, Three.js/R3F, Framer Motion, etc.)

Heavy demo preview media (videos, `demo/assets`) was stripped on import to keep
the repo lean; each skill's `SKILL.md` (and any `references/`, `scripts/`) is
intact and functional.
